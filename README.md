# skepsis

> Is your backtest result real, or overfit?

Statistical diagnostics for backtest overfitting: Probabilistic & Deflated
Sharpe Ratio, Probability of Backtest Overfitting (CSCV), stationary block
bootstrap, and parameter-sensitivity maps — with a self-contained HTML report.

**Status: pre-release, under active development. Not yet on PyPI.**
